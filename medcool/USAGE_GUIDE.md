## 🤖 **1. Telegram Bot - все кнопки работают:**

### 📱 **Основные команды:**
```
/start     - Главное меню с кнопками
/raspis    - Расписание на сегодня
/today     - Расписание на сегодня  
/tomorrow  - Расписание на завтра
/week      - Расписание на неделю
/open      - Открыть веб-сайт
/settings  - Настройки бота
/settime ЧЧ:ММ - Установить время рассылки
/help      - Помощь
```

### 🎮 **Кнопки в боте:**

#### Главное меню (/start):
```
📅 Сегодня    📆 Завтра
📋 Вся неделя  🌐 Открыть сайт
```

#### В расписании:
```
📅 Сегодня    📆 Завтра
📋 Вся неделя  📆 Другой день
🌐 Открыть сайт  🔙 Главное меню
```

#### В настройках:
```
🕐 Изменить время
📅 Расписание
🔙 Главное меню
```

### ⚙️ **Настройки времени рассылки:**

#### Команда `/settings`:
```
⚙️ Настройки бота

🕐 Время ежедневной рассылки: 06:00
📧 Рассылка включена: ✅ Да

🎯 Доступные команды:
• /settime ЧЧ:ММ - установить время рассылки
• /settings - показать настройки

💡 Пример: /settime 07:30

[🕐 Изменить время] [📅 Расписание] [🔙 Главное меню]
```

#### Команда `/settime`:
```
/settime 07:30
✅ Время рассылки изменено на 07:30

Теперь расписание будет приходить в 07:30 каждый день.
```
